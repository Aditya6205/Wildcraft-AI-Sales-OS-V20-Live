Wildcraft AI Sales OS V20 is a portfolio-grade sales intelligence operating system combining executive analytics, regional intelligence, India state-level revenue intelligence, pipeline and account monitoring, inventory signals, and an AI-assisted Decision Copilot.

## Highlights

- Executive Command Center with KPI and decision intelligence
- AI Decision Copilot with 3,000+ semantic training / benchmark questions
- Multi-intent reasoning and management-focused response modeling
- Latest question and answer displayed first
- Regional Intelligence dashboard
- Interactive India state-level revenue intelligence map
- Revenue, growth, target achievement and regional ranking
- Strongest / weakest region detection and action prioritization
- Pipeline, account-health and inventory analytics
- Wildcraft × Wiki brand-aware intelligence
- Premium enterprise UI, responsive layouts and motion system

## V20 + Regional Intelligence

This build keeps the V20 Copilot, training corpus, reasoning logic, dashboards and motion system while incorporating the strongest regional intelligence capabilities from the earlier V17 concept.

The live deployment loads an immutable compressed V20 application payload from the public `Wildcraft-AI-Sales-OS` repository and applies the duplicate-render correction before the dashboard mounts. This keeps the deployment lightweight while preserving the V20 feature set.
